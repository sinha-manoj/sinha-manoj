### 🏛 System Design & Engineering Principles

* **Fault-Tolerant & Asynchronous by Design:** Leveraging circuit breakers, dead-letter queues (DLQ), and idempotent consumers to ensure self-healing microservices.
* **Database & Query Efficiency:** Index optimization, connection pooling with PgBouncer, and cache-aside patterns with Redis to preserve database headroom under high QPS.
* **Production Observability:** Instrumenting distributed tracing via OpenTelemetry and Prometheus alerting to keep p95/p99 latency within SLA targets.
* **Automation First:** Enforcing automated unit/integration tests with `pytest`, pre-commit hooks, and Terraform drift detection in CI/CD pipelines.
